# Daymark

Daymark is een persoonlijke webapplicatie waarmee je je doelen, gewoontes en dagelijkse voortgang kunt bijhouden.

Het project is gemaakt met **PHP, MySQL/MariaDB, HTML, CSS en JavaScript**. Ik werk hierbij met **Object-Oriented Programming (OOP)** en een database om de gegevens van gebruikers op te slaan.

## Wat kun je met Daymark?

Met Daymark kun je onder andere:

* 🎯 Persoonlijke doelen aanmaken en bijhouden
* ✅ Dagelijkse gewoontes registreren
* 📊 Je voortgang bekijken
* 📝 Dagelijkse check-ins invullen
* 😊 Je stemming en energieniveau bijhouden
* 😴 Je slaap en productiviteit registreren
* 🔐 Inloggen en je eigen gegevens beheren

## Technologieën

* **PHP** – Backend en applicatielogica
* **MySQL / MariaDB** – Database
* **HTML** – Structuur van de pagina's
* **CSS** – Styling en layout
* **JavaScript** – Interactieve onderdelen
* **PDO** – Verbinding met de database
* **OOP** – Classes en methods voor de PHP-applicatie

## Database

Daymark maakt gebruik van een relationele database. De belangrijkste tabellen zijn:

* `users` – gebruikersgegevens
* `goals` – persoonlijke doelen en voortgang
* `habits` – dagelijkse gewoontes
* `habit_logs` – bijgehouden gewoontes
* `daily_checkins` – dagelijkse check-ins en resultaten

De tabellen zijn gekoppeld aan een gebruiker via `user_id`, zodat iedere gebruiker zijn eigen gegevens kan beheren.
